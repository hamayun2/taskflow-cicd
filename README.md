# TaskFlow CI/CD

TaskFlow CI/CD – A task management web app demonstrating automated CI/CD using GitHub Actions, Docker, and Render.

## Project Overview

TaskFlow is a modern task management application that showcases best practices in DevOps and CI/CD automation. The application is built with HTML, CSS, and JavaScript, containerized using Docker, and deployed automatically using GitHub Actions and Render.

## Features

- **Task Management**: Create, view, and manage your tasks efficiently
- **User Profile**: Manage your personal profile and settings
- **Task Tracking**: Monitor completed and pending tasks
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **CI/CD Pipeline**: Automated testing, building, and deployment

## Tech Stack

- **Frontend**: HTML5, CSS3
- **Build Tool**: Parcel
- **Containerization**: Docker & Docker Compose
- **CI/CD**: GitHub Actions
- **Deployment**: Render
- **Linting**: HTMLHint, Stylelint
- **Runtime**: Node.js (Alpine), Nginx
